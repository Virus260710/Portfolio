Kinof — Computer Room Booking & Management System

An end-to-end platform where students book lab machines and admins monitor them in real time. Built as a multi-service system with a hard security boundary: clients never touch the database or face engine directly — everything is brokered by the backend.

  • Face-recognition check-in via FastAPI + InsightFace — stores only 512-dim embeddings, never raw face images.
  • OTP booking flow with single-use, expiring tokens kept as HMAC hashes server-side.
  • JWT auth & roles for user, admin, and Kiosk interfaces.
  • Windows tracking agents reporting machine status & running programs, each with its own hashed API key.
  • Browser extension for domain-level tracking/blocking — logs domains only, no paths or content.
