01 — Flagship

Kinof

Computer-room booking & management

A multi-service platform where students book lab machines and admins watch them in real time. Clients never touch the database or the face engine directly — everything passes through the backend, which is the only trust boundary that matters.

  • Face check-in on FastAPI + InsightFace. Stores 512-dim embeddings, never raw images.
  • OTP booking with single-use, expiring tokens kept as HMAC hashes server-side.
  • Windows agents report machine status and running programs, each with its own hashed API key.
