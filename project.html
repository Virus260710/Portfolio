01 — Flagship

Kinof

Computer-room booking & management system

An end-to-end platform for booking and managing lab machines. It's a multi-service system built around one rule: the client is never trusted. Every request to the database or the face engine is brokered by the backend.

  • Face-recognition check-in — FastAPI + InsightFace, storing only 512-dimension embeddings, never raw face images.
  • OTP booking flow — single-use, expiring tokens held as HMAC hashes server-side.
  • JWT auth & roles across user, admin, and kiosk interfaces.
  • Windows tracking agents reporting machine status and running programs, each with its own hashed API key.
  • Browser extension for domain-level tracking — logs domains only, no paths or content.
