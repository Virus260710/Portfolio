Kinof — Computer Room Booking & Management

// flagship

A full-stack platform for booking and managing computer rooms, built as a multi-service system with a strict security boundary. Students reserve machines and check in with face recognition; admins monitor every machine in real time. Clients never talk to the database or face engine directly — the backend is the single source of truth for auth, bookings, and agent commands.

Key engineering decisions

  • Privacy-first face check-in — the face service only validates image quality and returns a 512-value embedding; raw photos are never stored.
  • Single-use OTP bookings — tokens expire and are stored only as HMAC hashes on the backend.
  • Hard trust boundary — Browser & Kiosk can't reach MySQL or the face service directly; the face service accepts the backend only, via a shared API key.
  • Per-machine agents — each Windows agent carries its own API key (backend keeps only the hash) and sends heartbeats, program status, and executes admin commands.
  • Scoped browser extension — reports and blocks by domain only; no paths, queries, content, or passwords.
  • Migration-driven DB — base schema plus migrations for tracking, face, admin, entry OTP, and auth tokens.
